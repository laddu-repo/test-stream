# AniKai Nuvio Plugin

## Installation

1. Open Nuvio app
2. Go to Settings → Local Scrapers
3. Add this URL:
   ```
   https://raw.githubusercontent.com/laddu-repo/test-stream/main/manifest.json
   ```
4. Enable AniKai scraper

## Features

- Anime streaming with sub and dub support
- TMDB integration for proper season/episode mapping
- Multiple quality options (1080p, 720p, 480p, 360p)
- Automatic absolute episode calculation from TMDB seasons
